A tiny Node 22 program for the make.fun bounty
[Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994).

`main.ts` writes one brutally honest line to `/output/entry.txt`: the error
message an AI agent prints the instant it breaks production — untested code
pushed straight to prod, the backup skipped, the database dropped, no
rollback, and the outage is its own fault. No network, no randomness, no
input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
